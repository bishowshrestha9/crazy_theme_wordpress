# Product Card Post Scanner & CSV Exporter

A standalone WordPress plugin to scan all posts, pages, and custom post types across your site, detect where **Product Card** Gutenberg blocks are used, and export a formatted CSV list of post names and details.

## Features
- **Comprehensive Scanning**: Scans all public post types (Posts, Pages, CPTs) and statuses (Published, Drafts, Scheduled, Private).
- **Multi-Block Pattern Support**: Detects `product-card-plugin/product-card`, `product-card/card`, `cardplugin/card`, and custom product card blocks.
- **Product Name Detection**: Extracts product names attached to card attributes.
- **CSV Export**: One-click export of Post ID, Post Name/Title, Post URL, Edit Link, Post Type, Post Status, Card Count, Product Names, and Published Date.
- **Interactive Dashboard**: Metric cards, real-time live search, progress bar, and filters.

## Installation
1. Upload the `product-card-post-scanner` folder (or install the `product-card-post-scanner.zip` file) into `/wp-content/plugins/`.
2. Activate **Product Card Post Scanner & CSV Exporter** via WordPress Admin > Plugins.
3. Click **Card Scanner** in the left menu to start scanning and export your CSV.
