# Site Info Plugin

## Description
A comprehensive WordPress plugin that analyzes and displays detailed information about your site including:

- **All Links**: Internal and external links from all posts and pages
- **External Links**: All outbound links
- **Affiliate Links**: Automatically detected affiliate URLs
- **Pretty Links**: Links from Pretty Links plugin and custom redirects
- **Products**: WooCommerce products and custom product post types
- **Site Overview**: WordPress version, PHP, MySQL, total posts, pages, users
- **Images**: All uploaded images
- **Plugins**: Active plugins list
- **Theme Information**: Current theme details
- **Enqueued Assets**: Loaded scripts and stylesheets count

## Features
- ✅ One-click site analysis
- ✅ Comprehensive link detection and categorization
- ✅ Affiliate link auto-detection
- ✅ Pretty Links integration
- ✅ WooCommerce product support
- ✅ Custom post type detection
- ✅ Clean, organized data display
- ✅ Export-ready data structure
- ✅ Real-time analysis with AJAX

## Installation
1. Upload the `SiteInfoPlugin` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to "Site Info" in the admin menu
4. Click "Add New" to create a new analysis
5. Click "Fetch Site Info" button to analyze your site

## Usage
1. Create a new Site Info entry
2. (Optional) Enter a target URL to analyze a different site
3. Click "Fetch Site Info" button
4. Wait for analysis to complete
5. View comprehensive results below

## Data Collected
- Site name, URL, description
- WordPress, PHP, MySQL versions
- Total posts, pages, custom post types
- All internal and external links
- Affiliate links (auto-detected)
- Pretty Links (if plugin is active)
- Products (WooCommerce and custom)
- Images with alt text
- Active plugins and theme info
- Enqueued scripts and styles

## Requirements
- WordPress 5.0 or higher
- PHP 7.0 or higher
