# 📖 Supplement Page Builder - Quick Guide

## 🎨 How to Add Header Background Image & Change Theme Color

### Step 1: Edit Your Supplement Page
1. Go to WordPress Admin → **Supplement Pages** → **Edit your page**

### Step 2: Find "Page Settings" in Right Sidebar
Look for the **"⚙️ Page Settings"** meta box in the **RIGHT SIDEBAR** (top section)

You'll see two fields:

#### 🖼️ Header Background Image URL
- Paste any image URL here (e.g., `https://example.com/header-image.jpg`)
- **Leave empty** for a solid color background
- Image will cover the full header area

#### 🎨 Theme Color
- Choose from dropdown:
  - **Green** (Default) - `#10B981`
  - **Blue** - `#6BA3F8`
  - **Red** - `#EF4444`
  - **Black** - `#1F2937`
- This color affects:
  - Header background (if no image)
  - Section borders
  - Buttons
  - Links
  - Product numbers

### Step 3: Click "Update" to Save

## 🚀 Quick Start

### Add Blocks by Typing:
In the content editor, type **`/`** and you'll see:

- `/top-choices` → Product ranking table
- `/research` → Research documents with download buttons
- `/comparison` → Comparison table (paste from anywhere!)
- `/faq` → Frequently Asked Questions
- `/source` → Source documents & disclosure
- `/disclaimer` → Yellow disclaimer box

### Tips:
- 💡 Drag blocks to reorder them
- 💡 Each block has its own settings
- 💡 Fill all fields for best appearance
- 💡 Preview before publishing
