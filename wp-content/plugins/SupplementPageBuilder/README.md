# Supplement Page Builder

A flexible WordPress plugin for creating supplement review pages with block-based components.

## Features

- **Custom Post Type**: "Supplement Pages" with dedicated admin interface
- **Block-Based Components**: Build pages using modular blocks
- **Copy/Paste Table Support**: Easily paste tables from Excel or Google Sheets
- **Flexible Layout**: Show/hide individual blocks per page
- **Responsive Design**: Mobile-friendly out of the box

## Included Blocks

1. **Hero Section** - Main title and introductory content
2. **Top Choices Block** - List top products with badges and ratings
3. **Downloadable Research Block** - Add research document downloads
4. **Comparison Table Block** - Copy/paste tables from anywhere
5. **FAQ Block** - Frequently asked questions
6. **Source Documents & Disclosure Block** - Full transparency section
7. **Disclaimer Block** - Legal disclaimers and notices

## Installation

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to "Supplement Pages" → "Add New" to create your first page

## Usage

1. Create a new Supplement Page
2. Fill in the blocks you want to use
3. Use the Block Visibility sidebar to show/hide specific blocks
4. Publish and view your page

## Customization

- CSS: Edit `assets/css/supplement-styles.css`
- Template: Edit `templates/single-supplement-page.php`
